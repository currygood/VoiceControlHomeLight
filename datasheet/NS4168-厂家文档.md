# NS4168 I2S数字输入单声道D类音频功率放大器 使用说明

## 一、产品概述

NS4168是一款支持I2S数字音频信号输入、且输出具有防失真（NCN）功能的单声道D类音频功率放大器。芯片内置数模转换器（DAC）和多级D类调制器，具备出色的音频性能。

通过I2S数字音频串行接口传送音频信号至放大器，可以显著降低噪声源对所传输音频的影响，同时避免了MCU主控芯片内置音频解码DAC所带来的噪声，最终获得较高的信噪比以及较小的失真度。其闭环数字输入设计保留了数字放大器的优势，同时又具有极佳的PSRR和音频性能。与其他D类架构相比，采用扩频脉冲密度调制可实现较低的EMI干扰和最高的音频效率。

NS4168为单声道音频功放，左右声道选择通过CTRL管脚电平设置。立体声产品可选用两个芯片实现。

## 三、应用范围

NS4168特别适用于对功耗敏感且易产生干扰的环境，典型应用包括：

- MP3/PMP
- Mini音箱（蓝牙音响、WiFi音响）
- 数码相框
- 平板电脑

## 六、应用说明

### 6.1 I2S数字音频接口

NS4168支持标准I2S数字音频信号输入（BCLK延迟一个时钟）。标准I2S有三个主要信号：

- **BCLK（位时钟）** ：对应数字音频的每一位数据
- **LRCLK（帧时钟）** ：用于切换左右声道数据。LRCLK为“1”表示传输右声道数据，为“0”表示传输左声道数据。LRCLK的频率通常设定为音频信号采样频率
- **SDATA（串行数据）** ：以二进制补码形式传输，先传输最高位MSB

**时序要求：**





| 参数  | 最小值 | 描述                                   |
| :---- | :----- | :------------------------------------- |
| tBIH  | 40ns   | BCLK低电平脉冲宽度                     |
| tBIH  | 40ns   | BCLK高电平脉冲宽度                     |
| tUS   | 10ns   | LRCLK或SDATA边沿到BCLK上升沿的建立时间 |
| tLIH  | 10ns   | BCLK上升沿到LRCLK或SDATA边沿的保持时间 |
| tSIS  | 10ns   | SDATA到BCLK上升沿的建立时间            |
| tSIIH | 10ns   | BCLK上升沿到SDATA的保持时间            |

### 6.2 采样频率与BCLK速率支持

NS4168内部LRCLK时钟应用范围为**128kHz ~ 6.144MHz**（MCLK时钟范围为2.048MHz ~ 24.576MHz）。

不同采样频率支持的BCLK速率如下：





| 采样频率Fs | 支持的BCLK速率                                |
| :--------- | :-------------------------------------------- |
| 8kHz       | 128k / 192k / 256k / 384k / 512k Hz           |
| 16kHz      | 256k / 384k / 512k / 768k / 1.024M Hz         |
| 32kHz      | 512k / 768k / 1.024M / 1.536M / 2.048M Hz     |
| 44.1kHz    | 705.6k / 1.058M / 1.422M / 2.117M / 2.822M Hz |
| 48kHz      | 768k / 1.152M / 1.536M / 2.304M / 3.072M Hz   |
| 96kHz      | 1.536M / 2.304M / 3.072M / 4.608M / 6.144M Hz |

### 6.3 声道选择（CTRL管脚）

NS4168为单声道功放，通过CTRL管脚电平选择左声道或右声道信号：





| CTRL管脚电压 | 声道选择 |
| :----------- | :------- |
| 1.5V ~ VDD   | 右声道   |
| 0.9V ~ 1.15V | 左声道   |
| 0 ~ 0.4V     | 芯片关断 |

> **注意**：CTRL管脚悬空可能导致不稳定，不推荐使用。

### 6.4 防失真（NCN）功能

NS4168内置独特的防失真功能，可以有效防止：

- 输入信号过载导致的输出信号失真
- 电池电压下降导致的输出信号失真
- 在大功率输出时保护扬声器不被损坏

**工作原理**：放大器自动检测输出削顶失真，自动调整放大器的增益，达到防失真效果。

**相关时序参数**：

- NCN启动时间（tAT）：10ms（VDD=3.6V）
- NCN释放时间（tRL）：1.1s（VDD=3.6V）

### 6.5 保护电路

NS4168内置多重保护功能：





| 保护类型         | 触发条件                              | 恢复方式               |
| :--------------- | :------------------------------------ | :--------------------- |
| 过流保护（OCP）  | 输出引脚与电源/地短路，或输出之间短路 | 故障消除后自动恢复     |
| 过热保护（OTP）  | 芯片温度过高                          | 温度下降后自动恢复     |
| 欠压保护（UVLO） | 电源电压过低                          | 电源电压恢复后自动启动 |

### 6.6 电源滤波电容选择

电源旁路设计对噪声性能及电源电压抑制性能至关重要。设计中要求滤波电容尽量靠近芯片电源脚。

**推荐配置**：100μF电解电容并联1μF陶瓷电容。

### 6.7 Layout建议

NS4168属于D类放大器，布局时应考虑EMI干扰。以下措施可最大限度降低EMI干扰：

1. **输出走线**：功放输出到喇叭的走线尽量短、尽量宽，且尽可能远离敏感信号线和电路
2. **电源退耦**：功放电源脚的退耦电容尽可能靠近芯片引脚
3. **星形接法**：电源线、地线最好采用星形接法
4. **磁珠和电容**：在空间受限等恶劣环境下，可在输出端加磁珠和电容抑制EMI干扰，磁珠和电容应尽可能靠近芯片引脚

## 七、典型应用电路

NS4168外围电路简洁。基本连接方式如下：

- BCLK（主控GPIO）→ NS4168 BCLK
- LRCLK（主控GPIO）→ NS4168 LRCLK
- SDATA（主控GPIO）→ NS4168 SDATA
- CTRL → 接高电平（右声道）或分压电阻（左声道）或接地（关断）

**电源设计要点**：

- 工作电压范围：3.0V ~ 5.5V
- 推荐使用5V供电以获得最大输出功率（2.5W @ 4Ω）
- 建议为音频模块单独供电或使用高质量LDO稳压器
- 电源输入端添加100μF电解电容和1μF陶瓷电容进行滤波

## 八、测试说明

测量D类模式功放时，**低通滤波器是必须的**。可以用两个33μH的电感串联在负载电阻两端以等效扬声器。如果仅采用纯电阻代替扬声器负载，所测得的功率、效率、失真度等指标会比用扬声器做负载时差。

## 九、封装信息

NS4168采用**ESOP-8**封装，热阻参数：

- θJC（结到壳）：20°C/W
- θJA（结到环境）：80°C/W

## 十、注意事项

1. **电源电压**：不得超过5.5V，否则可能损坏芯片
2. **ESD防护**：芯片ESD等级为HBM 4000V / MM 2000V，操作时仍需注意防静电
3. **散热**：ESOP封装底部散热焊盘需充分接地，确保良好散热
4. **CTRL管脚**：不可悬空，应按需接高电平、低电平或分压电阻
5. **I2S格式**：NS4168仅支持标准I2S格式（BCLK延迟一个时钟），需确保主控I2S配置匹配
