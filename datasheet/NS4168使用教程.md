# NS4168 I²S 数字功放使用教程

## 模块概述

NS4168 是一款支持 I²S 数字音频输入的单声道 D 类音频功率放大器，内置 DAC 和多级 D 类调制器。本项目使用 NS4168 作为语音播报输出模块，接收 ESP32-S3 通过 I²S 发送的 PCM 音频数据，驱动扬声器播放语音。

## 技术规格

| 参数 | 规格 |
|------|------|
| 类型 | 单声道 D 类数字功放（I²S 输入） |
| 输出功率 | 2.5W（VDD=5V, RL=4Ω） |
| 工作电压 | 3.0V ~ 5.5V |
| 音频采样率 | 8kHz ~ 96kHz |
| 效率 | 80%（5V, 4Ω, 2.5W） |
| THD+N | 0.2%（5V, 4Ω, 1W） |
| 信噪比 | 85dB |
| 静态电流 | 13mA（5V, 空载） |
| 关断电流 | 1μA |
| 封装 | ESOP-8 |

## 引脚定义

| 引脚 | 名称 | 功能 | ESP32-S3 引脚 | 说明 |
|------|------|------|--------------|------|
| 1 | CTRL | 声道选择/关断控制 | 3.3V | 高电平=右声道，分压=左声道，低电平=关断 |
| 2 | LRCLK | I²S 帧时钟 | GPIO9 | 即 WS，由 MCU 提供 |
| 3 | BCLK | I²S 位时钟 | GPIO8 | 由 MCU 提供 |
| 4 | SDATA | I²S 串行数据 | GPIO10 | 由 MCU 发送 |
| 5 | VoN | 功放输出负端 | 扬声器- | BTL 输出 |
| 6 | VDD | 电源 | 5V/3.3V | 推荐 5V 供电以获得最大功率 |
| 7 | GND | 电源地 | GND | 必须与系统共地 |
| 8 | VoP | 功放输出正端 | 扬声器+ | BTL 输出 |

### CTRL 引脚说明

| CTRL 电压 | 功能 |
|-----------|------|
| 1.5V ~ VDD | 选择右声道 |
| 0.9V ~ 1.15V | 选择左声道 |
| 0 ~ 0.4V | 芯片关断 |

本项目 CTRL 接 3.3V（右声道），与 I²S 驱动的 `I2S_SLOT_MODE_MONO` 配合使用。

## 硬件连接

### 接线图

```
NS4168 (ESOP-8)           ESP32-S3
┌──────────────┐            ┌──────────────┐
│ VDD (Pin 6)  │───────────▶│ 5V / 3.3V    │
│ GND (Pin 7)  │───────────▶│ GND          │
│ BCLK (Pin 3) │───────────▶│ GPIO8 (BCLK)  │
│ LRCLK(Pin 2) │───────────▶│ GPIO9 (LRCK)  │
│ SDATA(Pin 4) │───────────▶│ GPIO10 (DIN)  │
│ CTRL (Pin 1) │───────────▶│ 3.3V（右声道） │
│ VoP  (Pin 8) │───────────▶│ 扬声器 +      │
│ VoN  (Pin 5) │───────────▶│ 扬声器 -      │
└──────────────┘            └──────────────┘
```

### 电源去耦

```
VDD ──┬── 100μF 电解电容 ── GND
      └── 1μF 陶瓷电容   ── GND
```

电容尽量靠近芯片 VDD 引脚（Pin 6）。

### 扬声器连接

NS4168 为 BTL（桥接负载）输出，扬声器直接连接 VoP 和 VoN，**无需隔直电容**，也**无需外部低通滤波器**（Class D 内部已处理）。

```
NS4168 VoP (Pin 8) ──────────── 扬声器 +
NS4168 VoN (Pin 5) ──────────── 扬声器 -
```

> ⚠️ 扬声器两端都不能接地！VoP 和 VoN 是差分输出。

## 驱动架构

```

│  amplifier.c / amplifier.h              │  ← 应用层：功放控制、音量管理

│  - Amplifier_Play_Buffer()              │
│  - Amplifier_Set_Volume()               │

```

### 关键配置文件

| 文件 | 内容 |
|------|------|
| `amplifier.h` | 采样率、位深、音量范围宏定义 |
| `amplifier.c` | 功放初始化、播放、音量控制 |
| `i2s_driver.h`（TX 部分） | I²S GPIO 引脚、DMA 参数 |

## I²S 配置参数

```c
// i2s_driver.h 中的 TX 关键配置
#define I2S_TX_BCLK_GPIO      8
#define I2S_TX_LRCK_GPIO      9
#define I2S_TX_DIN_GPIO       10
#define I2S_TX_SAMPLE_RATE    16000
#define I2S_TX_BIT_DEPTH      16
#define I2S_TX_CHANNEL_NUM    1
#define I2S_TX_DMA_BUF_COUNT  8
#define I2S_TX_DMA_BUF_LEN    256
```

### I²S 格式要求

NS4168 仅支持**标准 I²S 格式**（MSB 延迟 1 个 BCLK 后输出），即 ESP-IDF 中的 Philips 标准：

| 参数 | 值 | 说明 |
|------|-----|------|
| `slot_mode` | `I2S_SLOT_MODE_MONO` | 单声道，WS 频率 = 采样率 |
| `data_bit_width` | `I2S_DATA_BIT_WIDTH_16BIT` | 16 位 PCM |
| `bit_shift` | `true`（默认） | 标准 I²S，MSB 延迟 1 BCLK |
| `ws_pol` | `false`（默认） | 标准极性 |
| BCLK 频率 | 256kHz | = 16000 × 16 × 1（单声道） |

完整 I²S TX 初始化代码：

```c
// i2s_driver.c - I2s_Tx_Init()
esp_err_t I2s_Tx_Init(void)
{
    i2s_chan_config_t chanConfig = {
        .id = I2S_NUM_1,          // 播放用端口 1，录音用端口 0
        .role = I2S_ROLE_MASTER,
        .dma_desc_num = 8,
        .dma_frame_num = 256,
        .auto_clear = true,
    };

    i2s_new_channel(&chanConfig, &Tx_Handle, NULL);

    i2s_std_config_t stdConfig = {
        .clk_cfg = I2S_STD_CLK_DEFAULT_CONFIG(16000),
        .slot_cfg = I2S_STD_PHILIPS_SLOT_DEFAULT_CONFIG(
            I2S_DATA_BIT_WIDTH_16BIT,
            I2S_SLOT_MODE_MONO),
        .gpio_cfg = {
            .bclk = GPIO8,
            .ws   = GPIO9,
            .dout = GPIO10,
            .din  = I2S_GPIO_UNUSED,
        },
    };

    i2s_channel_init_std_mode(Tx_Handle, &stdConfig);
    i2s_channel_enable(Tx_Handle);
}
```

## 使用示例

### 基本播放流程

```c
#include "amplifier.h"

void Play_Example(void)
{
    // 1. 初始化功放
    Amplifier_Init();

    // 2. 设置音量（0-100%）
    Amplifier_Set_Volume(80);

    // 3. 准备 PCM 数据（16-bit 有符号，单声道）
    int16_t pcmBuffer[16000];  // 1 秒 @ 16kHz
    // ... 填充 PCM 数据 ...

    // 4. 播放
    size_t bytesWritten = 0;
    Amplifier_Play_Buffer((uint8_t *)pcmBuffer,
                          16000 * sizeof(int16_t),
                          &bytesWritten, portMAX_DELAY);

    // 5. 释放资源
    Amplifier_Deinit();
}
```

### 生成测试音（1kHz 正弦波）

```c
void Tone_Test(void)
{
    Amplifier_Init();

    int sampleRate = 16000;
    int duration = 3;  // 3 秒
    int totalSamples = duration * sampleRate;
    int16_t amplitude = 20000;

    int16_t *toneBuf = malloc(totalSamples * sizeof(int16_t));
    for (int i = 0; i < totalSamples; i++)
    {
        toneBuf[i] = (int16_t)(amplitude *
            sinf(2.0f * 3.1415926f * 1000 * i / sampleRate));
    }

    // 播放
    size_t bytesWritten = 0;
    size_t totalBytes = totalSamples * sizeof(int16_t);
    Amplifier_Play_Buffer((uint8_t *)toneBuf, totalBytes,
                          &bytesWritten, portMAX_DELAY);

    free(toneBuf);
    Amplifier_Deinit();
}
```

### 完整录音+播放测试

```c
#include "microphone.h"
#include "amplifier.h"

void Record_Playback_Test(void)
{
    // 1. 初始化麦克风（录音）
    Microphone_Init();

    // 2. 初始化功放（播放）
    Amplifier_Init();

    // 3. 录音 10 秒
    int16_t *recordBuf = heap_caps_malloc(
        160000 * sizeof(int16_t), MALLOC_CAP_SPIRAM);
    size_t samplesRead = 0;
    Microphone_Read_Pcm16(recordBuf, 160000, &samplesRead, portMAX_DELAY);

    // 4. 播放录音
    size_t bytesWritten = 0;
    Amplifier_Play_Buffer((uint8_t *)recordBuf,
                          samplesRead * sizeof(int16_t),
                          &bytesWritten, portMAX_DELAY);

    // 5. 清理
    heap_caps_free(recordBuf);
    Amplifier_Deinit();
    Microphone_Deinit();
}
```

## API 参考

### Amplifier_Init()

初始化 NS4168 功放，包括 I²S TX 接口配置。

```c
esp_err_t Amplifier_Init(void);
```

- **返回值**：`ESP_OK` 成功，否则失败
- **注意**：初始化后功放即可播放，默认音量 80%

### Amplifier_Deinit()

关闭功放，释放 I²S 资源。

```c
esp_err_t Amplifier_Deinit(void);
```

### Amplifier_Play_Buffer()

播放 PCM 音频数据（阻塞式）。

```c
esp_err_t Amplifier_Play_Buffer(
    const uint8_t *buffer,     // [in]  PCM 数据缓冲区
    size_t size,               // [in]  数据字节数
    size_t *bytes_written,     // [out] 实际写入的字节数
    uint32_t timeout           // [in]  超时时间（RTOS tick）
);
```

- **数据格式**：16-bit 有符号 PCM，单声道，小端序
- **阻塞行为**：会阻塞直到所有数据写入 DMA 缓冲区或超时
- **返回值**：`ESP_OK` 成功

### Amplifier_Set_Volume()

设置软件音量（0-100%）。

```c
esp_err_t Amplifier_Set_Volume(uint8_t volume);
```

- **volume**：0 ~ 100，超出范围自动截断
- **注意**：当前为软件音量跟踪，实际音量调节需在 PCM 数据层实现

### Amplifier_Get_Volume()

获取当前音量设置。

```c
uint8_t Amplifier_Get_Volume(void);
```

## 软件音量调节

NS4168 本身没有硬件音量控制引脚，需要在软件层对 PCM 数据做缩放：

```c
void Volume_Adjust(int16_t *pcmBuffer, size_t samples, float volume)
{
    // volume 范围 0.0 ~ 1.0
    for (size_t i = 0; i < samples; i++)
    {
        pcmBuffer[i] = (int16_t)(pcmBuffer[i] * volume);
    }
}

// 使用示例：音量降到 50%
Volume_Adjust(pcmBuffer, 1024, 0.5f);
```

## I²S 双端口共存说明

本项目同时使用两个 I²S 端口：

| 端口 | 方向 | 用途 | 设备 |
|------|------|------|------|
| I2S_NUM_0 | RX | 录音 | INMP441 麦克风 |
| I2S_NUM_1 | TX | 播放 | NS4168 功放 |

### ⚠️ 重要限制

1. **禁止混用新旧驱动**：ESP-IDF v5.x 不允许 `driver/i2s.h`（legacy）和 `driver/i2s_std.h`（新版）同时使用
2. **TX 和 RX 可以同时运行**：两个端口独立，互不干扰
3. **INMP441 必须用 I2S_NUM_0**：因此 NS4168 使用 I2S_NUM_1

## 常见问题排查

| 现象 | 可能原因 | 解决办法 |
|------|---------|---------|
| 完全无声 | CTRL 引脚电压不对 | 检查 CTRL 电压：1.5V~VDD=右声道，<0.4V=关断 |
| 完全无声 | I²S 格式不匹配 | NS4168 仅支持标准 I²S（`bit_shift=true`），不能用 `bit_shift=false` |
| 完全无声 | 扬声器接法错误 | VoP/VoN 差分接扬声器两端，都不能接地 |
| 声音很小 | 供电电压不足 | 推荐 5V 供电，3.3V 时功率大幅下降 |
| 声音断续/卡顿 | DMA 缓冲区太小 | 增大 `dma_buf_len` 到 256 或 512 |
| 有杂音/噪声 | 电源滤波不足 | 加 100μF 电解 + 1μF 陶瓷电容靠近 VDD |
| 有杂音/噪声 | 音频数据本身有噪声 | 检查 PCM 数据源，确认数据格式正确 |
| 芯片过热 | 散热不良 | ESOP-8 底部散热焊盘需充分接地 |
| 系统启动崩溃 | 新旧 I²S 驱动混用 | 统一使用新版 `driver/i2s_std.h` |

## Layout 建议

1. **输出走线**：VoP/VoN 到扬声器的走线尽量短、宽
2. **电源退耦**：100μF + 1μF 电容尽量靠近 VDD 引脚
3. **星形接地**：电源线、地线采用星形接法
4. **远离敏感信号**：功放输出走线远离 I²S 信号线和天线
