## 问题：
WebSocket 握手时用 CONFIG_WS_BUFFER_SIZE 大小的 buffer 接收 HTTP 响应头。你当前 sdkconfig
里这个值是 1024（默认值）。豆包 openspeech.bytedance.com 的 WebSocket 升级响应头超过了 1024 字节 导致 buffer写满后直接报错断开。

## 解决：
把 CONFIG_WS_BUFFER_SIZE 从 1024 改大即可。
