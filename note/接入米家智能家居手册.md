## 1. 方案A 原理与架构

### 1.1 一句话原理

> 在 ESP32 上跑一个 **MQTT 客户端**，连到**巴法云**（bemfa.com，一个免费的国内物联网云平台）；在小米手机**米家 App** 里把巴法云账号绑定为"其他平台设备"。这样米家 App / 小爱同学发指令 → 巴法云 → MQTT → ESP32 → `LED_Control_Set_Light()` 控制灯。

### 1.2 数据链路

```
小米手机（米家 App / 小爱同学）
        │ 米家云（互联网）
        ▼
巴法云 bemfa.com（MQTT Broker，端口 9501，client_id = 巴法云私钥）
        │ MQTT 发布/订阅（主题如 bedroom002 / livingroom002）
        ▼
ESP32-S3（MQTT 客户端，新组件 Bemfa_MQTT）
        │ LED_Control_Set_Light() / LED_Control_Get_Light()
        ▼
卧室灯 / 客厅灯（RGB PWM）
```

### 1.3 为什么选它

- **零认证**：不需要申请小米官方开发者平台、不需要企业资质。
- **改动小**：本项目 `sdkconfig` 已启用 ESP-MQTT（`CONFIG_MQTT_PROTOCOL_311=y`），只需新增一个组件。
- **体验完整**：米家 App 出现真实灯设备卡片，能开关、调亮度；小爱音箱 / 手机小爱 App 可直接语音控制。
- **成本 0**：巴法云免费注册使用。

## 3. 第一步：巴法云平台配置

1. 打开 <https://cloud.bemfa.com>，注册并登录（邮箱或微信扫码）。
2. 在**控制台**找到并复制 **私钥 UID** —— 它就是后面 MQTT 的 `client_id`，**务必保密**。
3. 创建两个主题：
   - 卧室灯：`bedroom002`
   - 客厅灯：`livingroom002`
4. 修改主题**昵称**（控制台点主题昵称即可改名），如"卧室灯""客厅灯"。**米家 App 里显示的名称就是主题昵称**。

### 3.1 主题命名规则（重要）

巴法云通过**主题名后三位**决定设备类型，同步到米家时按类型显示：

| 后三位 | 设备类型 | 备注 |
| ------ | -------- | ---- |
| 001 | 插座 | 开关 |
| **002** | **灯泡** | **本方案使用：开关 + 亮度 + 颜色/色温** |
| 003 | 风扇 | |
| 004 | 传感器 | |
| 005 | 空调 | |
| 006 | 开关 | |
| 009 | 窗帘 | |
| 010 | 温控器 | |
| 011 | 热水器 | |
| 012 | 电视 | |
| 013 | 空气净化器 | |

> 注意：主题名**后三位必须是 002** 才会在米家显示为"灯"。名字其余部分随意，如 `bedroom002`、`wo_shi_deng002` 都可以。

## 4. 第二步：米家 App 绑定巴法云

1. 打开米家 App → **我的** → **其他平台设备** → **添加**。
2. 搜索 **"巴法"** → 登录你的巴法云账号。
3. 绑定成功后点击 **同步设备**，即可看到"卧室灯""客厅灯"两张设备卡片。

### 4.1 语音控制

- 绑定后可直接对小爱音箱或**手机上的小爱 App** 说："小爱同学，打开卧室灯 / 关掉客厅灯 / 把卧室灯调亮一点"。
- **不需要购买小爱音箱**也能用手机小爱 App 语音控制；米家 App 里的按键控制则完全不需要语音设备。

## 5. 第三步：ESP32 端代码集成

### 5.1 巴法云灯设备消息协议

灯设备（主题后缀 002）的消息格式：

```
on                    # 开灯
off                   # 关灯
on#亮度值              # 开灯并设置亮度，亮度范围 1~100，如 on#80
on#亮度值#RGB值        # 开灯 + 亮度 + RGB 颜色（十进制整数）
on#亮度值#色温值        # 开灯 + 亮度 + 色温
```

**状态上报**：设备把最新状态**按同样格式发布（publish）回主题**，巴法云会自动同步给米家 App，保证 App 显示与实际一致。

> 说明：巴法云对"灯"的颜色与色温使用同一字段，米家 App 侧对 RGB 颜色控制映射不完善（详见第 7 节），建议米家 App 里做开关 + 亮度，RGB 调色留给语音/网页。

### 5.1.1 RGB 颜色值格式详解（重要）

#### ⚠️ 格式差异说明

米家 App 通过巴法云发送的 **RGB 颜色值为十进制整数**，而非十六进制字符串！

| 来源 | 格式示例 | 说明 |
| ---- | -------- | ---- |
| **米家 App 发送** | `on#30#16711680` | **十进制整数** |
| 手动测试（巴法云控制台） | `on#30#ff0000` | 十六进制字符串 |
| **设备上报** | `on#30#ff0000` | 十六进制字符串 |

#### 🔢 十进制转 RGB 算法

米家发送的十进制颜色值需要通过**位运算**拆分为 R、G、B 三个分量：

```c
// 示例：16711680 (纯红色)
// 二进制表示：00000000 11111111 00000000 00000000
//              ^^^^^^^^ ^^^^^^^^ ^^^^^^^^ ^^^^^^^^
//                未用    R=255    G=0      B=0

unsigned int color_val = 16711680;

st.color_r = (color_val >> 16) & 0xFF;   // 提取高8位 → 255 (0xFF) - 红色
st.color_g = (color_val >> 8) & 0xFF;    // 提取中8位 → 0         - 绿色
st.color_b = color_val & 0xFF;           // 提取低8位 → 0         - 蓝色
```

#### 📊 常见颜色对照表

| 颜色 | 十进制值 | 十六进制 | R | G | B | 消息示例 |
| ---- | -------- | ------- --- | - | - | - | -------- |
| **红色** | **16711680** | `0xFF0000` | 255 | 0 | 0 | `on#100#16711680` |
| **绿色** | 65280 | `0x00FF00` | 0 | 255 | 0 | `on#80#65280` |
| **蓝色** | 255 | `0x0000FF` | 0 | 0 | 255 | `on#50#255` |
| **白色** | 16777215 | `0xFFFFFF` | 255 | 255 | 255 | `on#100#16777215` |
| **黄色** | 16776960 | `0xFFFF00` | 255 | 255 | 0 | `on#70#16776960` |
| **青色** | 65535 | `0x00FFFF` | 0 | 255 | 255 | `on#60#65535` |
| **品红** | 16711935 | `0xFF00FF` | 255 | 0 | 255 | `on#90#16711935` |
| **橙色** | 16753920 | `0xFFA500` | 255 | 165 | 0 | `on#85#16753920` |

#### ✅ 正确的解析代码实现

```c
static void Bemfa_Handle_Message(const char *topic, const char *data)
{
    // ...省略前序代码...

    if (strcmp(data, "on") == 0) {
        st.is_on = true;
    } else if (strcmp(data, "off") == 0) {
        st.is_on = false;
    } else {
        int  brightness = 0;
        unsigned int color_val = 0;  // 使用单个变量接收十进制颜色值

        // 优先尝试解析带颜色的指令（十进制格式）
        if (sscanf(data, "on#%d#%u", &brightness, &color_val) == 2) {
            st.is_on      = true;
            st.brightness = (uint8_t)brightness;
            st.color_r    = (uint8_t)((color_val >> 16) & 0xFF);  // 提取红色分量
            st.color_g    = (uint8_t)((color_val >> 8) & 0xFF);   // 提取绿色分量
            st.color_b    = (uint8_t)(color_val & 0xFF);          // 提取蓝色分量
        } else if (sscanf(data, "on#%d", &brightness) == 1) {     // 仅亮度
            st.is_on      = true;
            st.brightness = (uint8_t)brightness;
        } else {
            ESP_LOGW(TAG, "无法解析的指令: %s", data);
            return;
        }
    }

    // ...后续代码...
}
```

#### ⚠️ 常见错误示例

**❌ 错误写法：使用十六进制格式符**

```c
// 错误！无法解析米家发送的十进制值
if (sscanf(data, "on#%d#%2x%2x%2x", &brightness, &r, &g, &b) == 4)
//                  ^^^^^^^^^^^^
//            这是十六进制解析，但米家发的是 16711680 而非 ff0000
```

**✅ 正确写法：使用十进制格式符 + 位运算**

```c
// 正确！先接收十进制整数，再位运算拆分
if (sscanf(data, "on#%d#%u", &brightness, &color_val) == 2) {
    st.color_r = (color_val >> 16) & 0xFF;
    st.color_g = (color_val >> 8) & 0xFF;
    st.color_b = color_val & 0xFF;
}
```

### 5.3 代码示例

**Bemfa_MQTT.h**

```c
#ifndef __BEMFA_MQTT_H__
#define __BEMFA_MQTT_H__

#include "esp_err.h"

/**
 * @brief 初始化并启动巴法云 MQTT 客户端
 * @return ESP_OK 成功
 */
esp_err_t Bemfa_MQTT_Init(void);

/**
 * @brief 把当前两路灯的状态上报到巴法云（米家 App 同步显示）
 * @return ESP_OK 成功
 */
esp_err_t Bemfa_MQTT_Report_State(void);

#endif
```

**Bemfa_MQTT.c**

```c
#include "Bemfa_MQTT.h"
#include "mqtt_client.h"
#include "esp_log.h"
#include "LED_Control.h"
#include <string.h>
#include <stdio.h>

#define TAG "BEMFA_MQTT"

/* ======================== 巴法云配置 =========================================== */

#define BEMFA_BROKER_URI    "mqtt://bemfa.com:9501"
#define BEMFA_CLIENT_ID     "此处填写巴法云私钥UID"   /* client_id = 巴法云私钥 */
#define BEMFA_TOPIC_BEDROOM    "bedroom002"          /* 卧室灯，灯泡设备 */
#define BEMFA_TOPIC_LIVINGROOM "livingroom002"       /* 客厅灯，灯泡设备 */

static esp_mqtt_client_handle_t s_client = NULL;

/* ======================== 工具函数 ============================================ */

static LED_ID Bemfa_Get_LED_ID(const char *topic)
{
    LED_ID led = { .id = 0, .name = "unknown" };

    if (strcmp(topic, BEMFA_TOPIC_BEDROOM) == 0) {
        led.id   = LED_ID_BEDROOM;
        led.name = "Bedroom";
    } else if (strcmp(topic, BEMFA_TOPIC_LIVINGROOM) == 0) {
        led.id   = LED_ID_LIVINGROOM;
        led.name = "Livingroom";
    }
    return led;
}

/* ======================== 指令处理 ============================================ */

/**
 * @brief 解析巴法云灯指令并控制对应灯
 *
 * 支持格式：
 *   on / off
 *   on#亮度(1~100)
 *   on#亮度#RRGGBB
 */
static void Bemfa_Handle_Message(const char *topic, const char *data)
{
    LED_ID led = Bemfa_Get_LED_ID(topic);
    if (led.id != LED_ID_BEDROOM && led.id != LED_ID_LIVINGROOM) {
        ESP_LOGW(TAG, "未知主题: %s", topic);
        return;
    }

    LED_Control_State st;
    if (LED_Control_Get_Light(led, &st) != ESP_OK) {
        return;
    }

    if (strcmp(data, "on") == 0) {
        st.is_on = true;
    } else if (strcmp(data, "off") == 0) {
        st.is_on = false;
    } else {
        int  brightness = 0;
        unsigned int r = 0, g = 0, b = 0;

        if (sscanf(data, "on#%d#%2x%2x%2x", &brightness, &r, &g, &b) == 4) {
            st.is_on      = true;
            st.brightness = (uint8_t)brightness;
            st.color_r    = (uint8_t)r;
            st.color_g    = (uint8_t)g;
            st.color_b    = (uint8_t)b;
        } else if (sscanf(data, "on#%d", &brightness) == 1) {
            st.is_on      = true;
            st.brightness = (uint8_t)brightness;
        } else {
            ESP_LOGW(TAG, "无法解析的指令: %s", data);
            return;
        }
    }

    if (LED_Control_Set_Light(led, st) == ESP_OK) {
        ESP_LOGI(TAG, "收到米家指令: topic=%s data=%s", topic, data);
        Bemfa_MQTT_Report_State();   /* 回传状态，保持米家 App 显示一致 */
    }
}

/* ======================== 状态上报 ============================================ */

esp_err_t Bemfa_MQTT_Report_State(void)
{
    if (s_client == NULL || !esp_mqtt_client_is_connected(s_client)) {
        return ESP_FAIL;
    }

    static const char *topics[LED_ID_MAX] = { BEMFA_TOPIC_BEDROOM, BEMFA_TOPIC_LIVINGROOM };

    for (int i = 0; i < LED_ID_MAX; i++) {
        LED_Control_State st;
        LED_ID led = { .id = i, .name = "led" };

        if (LED_Control_Get_Light(led, &st) != ESP_OK) {
            continue;
        }

        char payload[32];
        if (st.is_on) {
            snprintf(payload, sizeof(payload), "on#%d#%02x%02x%02x",
                     st.brightness, st.color_r, st.color_g, st.color_b);
        } else {
            snprintf(payload, sizeof(payload), "off");
        }

        esp_mqtt_client_publish(s_client, topics[i], payload, 0, 1, 1); /* QoS1 + retain */
    }
    return ESP_OK;
}

/* ======================== MQTT 事件回调 ======================================= */

static void mqtt_event_handler(void *handler_args, esp_event_base_t base,
                               int32_t event_id, void *event_data)
{
    esp_mqtt_event_handle_t event = event_data;

    switch ((esp_mqtt_event_id_t)event_id) {
    case MQTT_EVENT_CONNECTED:
        ESP_LOGI(TAG, "已连接巴法云");
        esp_mqtt_client_subscribe(s_client, BEMFA_TOPIC_BEDROOM, 1);
        esp_mqtt_client_subscribe(s_client, BEMFA_TOPIC_LIVINGROOM, 1);
        Bemfa_MQTT_Report_State();   /* 上线即上报一次真实状态 */
        break;

    case MQTT_EVENT_DATA: {
        char topic[64] = {0};
        char data[64]  = {0};
        int  tlen = (event->topic_len < (int)sizeof(topic) - 1) ? event->topic_len : (int)sizeof(topic) - 1;
        int  dlen = (event->data_len  < (int)sizeof(data)  - 1) ? event->data_len  : (int)sizeof(data)  - 1;
        memcpy(topic, event->topic, tlen);
        memcpy(data,  event->data,  dlen);
        Bemfa_Handle_Message(topic, data);
        break;
    }

    case MQTT_EVENT_DISCONNECTED:
        ESP_LOGW(TAG, "与巴法云断开，esp-mqtt 将自动重连");
        break;

    default:
        break;
    }
}

/* ======================== 初始化 ============================================== */

esp_err_t Bemfa_MQTT_Init(void)
{
    esp_mqtt_client_config_t mqtt_cfg = {
        .broker.address.uri = BEMFA_BROKER_URI,
        .credentials.client_id = BEMFA_CLIENT_ID,
        .session.keepalive = 60,
    };

    s_client = esp_mqtt_client_init(&mqtt_cfg);
    if (s_client == NULL) {
        ESP_LOGE(TAG, "MQTT 客户端创建失败");
        return ESP_FAIL;
    }

    esp_mqtt_client_register_event(s_client, ESP_EVENT_ANY_ID, mqtt_event_handler, NULL);
    return esp_mqtt_client_start(s_client);
}
```

> 提示：代码中的 `BEMFA_CLIENT_ID` 请替换为你的巴法云私钥，且**不要提交到公共 Git 仓库**；后续可改成 menuconfig/Kconfig 或 NVS 存储。

### 5.4 集成到 main.c

1. 顶部加 `#include "Bemfa_MQTT.h"`；
2. 在 `LED_Control_Init()` 之后（此时 Wi-Fi 已连接）调用：

```c
    // 初始化 LED 控制模块
    err = LED_Control_Init();
    if(err != ESP_OK)
    {
        ESP_LOGE(TAG, "LED Control init failed: %s", esp_err_to_name(err));
    }

    // 初始化巴法云 MQTT，接入米家 App / 小爱同学控制

```

`main/CMakeLists.txt` 的 REQUIRES 已包含 `App`，`Bemfa_MQTT.h` 随 App 组件自动加入头文件搜索路径，无需修改。

### 5.5 与 AI 语音控制的关系

- 现有云端 AI（`AI_Coud`）通过 Function Call `set_light / get_light` 控制灯，走的也是 `LED_Control_Set_Light() / LED_Control_Get_Light()`。
- MQTT 是**另一个命令入口**，两者共用同一套 LED 状态，天然一致、互不冲突。
- 无论哪个入口改灯，状态都存到 `LED_Control`，上报给巴法云时统一读 `LED_Control_Get_Light()`，避免显示不一致。

| 7 | 手机断开 Wi-Fi 用流量操作米家 App | 可远程控制（走公网） |
| 8 | 断电重启设备 | 上电后自动连 MQTT 并上报状态，米家 App 显示真实状态 |

## 7. 局限与注意事项

1. **RGB 颜色在米家 App 侧不完善**：巴法云把灯的颜色与色温映射为同一字段，米家 App 上调节颜色可能表现为色温/亮度，体验不佳。**建议米家 App 只做开关 + 亮度**；RGB 调色保留给语音 AI 或后续自建网页（见附录方案C）。
2. **依赖第三方云与公网**：巴法云免费但属于公共服务，断网或平台故障时米家控制不可用；本地语音唤醒词（ASR）不受影响，云端 AI 对话同样需要公网。
3. **链路时延**：指令走"米家云 → 巴法云 → MQTT"，通常 1~3 秒，非局域网即时。
4. **私钥保密**：巴法云私钥即 MQTT `client_id`，泄露等于任何人可控制你的灯；不要提交到公开仓库。
5. **一个主题 = 一个设备**：两路灯需要两个主题，米家 App 里是两个设备卡片。
6. **消息缓冲**：MQTT 指令不超过代码里的缓冲区（示例 64 字节），长度超限会被截断。
7. **不要与 OTA 冲突**：如需在 OTA 升级时暂停 MQTT（参考现有 OTA 暂停音频/WS 的做法），避免下载固件时内存/带宽争抢。

## 附录：接入方案对比（供后续学习）

> 以下为"让手机/米家生态控制自研灯"的几种主流路线，供后续学习参考。

### A. 巴法云桥接（本文方案）

- **原理**：ESP32 用 MQTT 连巴法云，米家账号绑定巴法云后显示为"灯"设备。
- **米家 App 能力**：开关 + 亮度（颜色/色温 App 侧体验差）。
- **小爱语音**：✔（音箱 / 手机小爱 App）。
- **难度**：低（本工程已具备 MQTT 支持）。
- **依赖**：第三方免费云 + 公网。
- **学习价值**：MQTT、云平台、状态同步。

### B. 小米IoT开发者平台（原生接入）

- **原理**：设备跑米家官方 **MiOT / MiIO** 协议，通过 <https://iot.mi.com> 创建产品（彩光灯模板），本地开发固件 + 米家**扩展程序**，刷 **Debug 版米家 App** 联调。
- **米家 App 能力**：原生设备，**彩色灯模板可支持 RGB**，体验最好。
- **限制**：个人开发者（2023 年开放内测）**不能上线产品、不能分享给他人**，只能自己账号控制；需内测名额与官方流程。
- **难度**：很高（协议栈 + 扩展程序 + 配网联调）。
- **学习价值**：MiOT / Miot-Spec 协议、米家扩展程序开发、设备配网流程。

### C. 手机网页 / 自建 App / 小程序

- **原理**：ESP32 内置 HTTP/WebSocket 服务器，手机浏览器直接控制（本工程已有配网网页与 WebSocket 基础）；远程控制可自建后端。
- **米家 App 能力**：无（不在米家生态内）。
- **能力**：开关 / 亮度 / **RGB 全支持**，局域网即时。
- **难度**：低 ~ 中。
- **学习价值**：HTTP、WebSocket、前端 / 小程序开发。

### D. Home Assistant 中继

- **原理**：ESP32 → MQTT/ESPHome → Home Assistant；HA 可通过巴法云插件（如 `genkin-he/bemfa`）把实体同步进米家 App，或直接用 HA App 控制。
- **米家 App 能力**：经巴法云同步（同方案A），或直接用 HA 获得更强功能。
- **能力**：最强——全屋联动、自动化、多平台语音（小爱 / 天猫 / 小度）。
- **难度**：高（需要一台常开的服务器：NAS / 树莓派 / 云主机）。
- **学习价值**：HA、ESPHome、自动化、智能家居全家桶。

### E. 成品米家灯 / 智能插座替换

- **原理**：直接购买米家智能灯 / 灯带 / 智能插座，开箱即用。
- **米家 App 能力**：原生，最好。
- **局限**：放弃自研 RGB PWM 硬件（或改造接线）。
- **适用**：不想折腾，追求开箱即用。

### 汇总对比表

| 维度 | A 巴法云 | B 小米IoT平台 | C 网页/自建 | D Home Assistant | E 成品灯 |
| ---- | -------- | ------------- | ----------- | ---------------- | -------- |
| 米家 App 内控制 | ✔ 灯(开关+亮度) | ✔ 原生(可 RGB) | ✘ | △ 经巴法云同步 | ✔ 原生 |
| RGB 颜色 | △ App 侧差 | ✔ | ✔ | △ | ✔ |
| 小爱语音 | ✔ | ✔ | ✘ | ✔ | ✔ |
| 开发难度 | 低 | 很高 | 低 | 高 | 无 |
| 依赖 | 第三方云 | 官方平台 | 无/自建后端 | 常开服务器 | 无 |
| 成本 | 0 | 0 | 0 | 服务器成本 | 灯钱 |
| 学习价值 | MQTT | 米家协议 | Web/小程序 | 全屋智能 | 无 |
| 适合场景 | 快速接入米家 | 研究原生协议 | 纯 DIY 控制 | 全屋智能玩家 | 开箱即用 |

### 学习路线建议

1. **入门**：先做方案A（本文），掌握 MQTT 与云平台状态同步。
2. **进阶·物联网**：方案C，把控制页做成 PWA / 小程序，学会前后端与 WebSocket。
3. **进阶·米家协议**：方案B，研究 Miot-Spec 与米家扩展程序（适合真正想"入伙"米家生态）。
4. **进阶·全屋智能**：方案D，部署 Home Assistant，学习 ESPHome 与自动化联动。
5. **反向学习**：用 `hass-xiaomi-miot` 把家里已有的米家设备接入 HA，理解设备发现与控制协议。
